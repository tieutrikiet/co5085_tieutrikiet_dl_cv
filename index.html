CO5085 · Deep Learning and Its Applications

Exercises & assignments in PyTorch

Four exercises and two assignments, each one a comparison backed by real experiments — runnable code plus measured results: metrics, plots and error cases, not just model definitions.

Tieu Tri Kiet PyTorch · Apple Silicon (MPS) Source on GitHub

Exercises

E1Planned

Image classification

Softmax on a flattened vector, an MLP, and a CNN on the same small image set — compared on accuracy, capacity and where each one fails.
E2Planned

Multi-head self-attention

MSA written from scratch and with torch.nn, over several tokenizations: patches, pixel/row, a CNN stem, and CLS + patches.
E3Planned

Sequence models

LSTM and GRU reading an image as a sequence of rows, measured against a feed-forward and CNN baseline on the same data.
E4Planned

Generative models

VAE, GAN and diffusion on an MNIST-like set — sample grids, latent-space visualization, and sample quality traded against compute.

Assignments

A1Planned

CNN vs. Transformer

A self-chosen large image dataset under several regimes: from scratch vs. pretrained, with the backbone frozen, partially frozen, or fully finetuned.
A2Planned

Pipeline + paper analysis

A self-chosen topic — detection, segmentation or similar — built into a working pipeline, alongside an analysis of one related paper.
Datasets are kept outside the repository and are not committed. See the README for setup and the expected data layout.
